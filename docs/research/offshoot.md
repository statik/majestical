# OffShoot (Hedge) — Research Report

## 1. Core purpose and target user

Verified media offload/ingest for video professionals. Copies from camera cards/drives to one or many destinations with checksum verification, plus organization (renaming, folder structures, filtering) and a paper trail (transfer logs, MHLs). Formerly named "Hedge"; rebranded to OffShoot in Oct 2023 ([hedge.co/products/offshoot](https://hedge.co/products/offshoot), [newsshooter.com](https://www.newsshooter.com/2023/10/04/hedge-becomes-offshoot/)). macOS + Windows; a cut-down "Solo" exists for iPad. Target users: DITs, data wranglers, shooters, media managers, post houses. Docs state it works for any files, not just media ([docs faq](https://docs.hedge.video/offshoot/faq)).

## 2. Key features

**Offload workflow** — Disks pane lists all mounted volumes; drag any to SOURCES or DESTINATIONS. Sources × destinations = N queued transfers, shown on the "Add Transfers" button. Source Folder / Destination Folder can scope to subfolders. Progress bars are color-coded: grey (indexing), dark blue (copy), light blue (verify/sidecar/log), green (clean), red (hardware/source checksum error), orange (integrity issue) ([overview](https://docs.hedge.video/offshoot/overview)).

**Verification** ([docs](https://docs.hedge.video/offshoot/features/verification)) — XXH64BE always computed from source reads; optional legacy MD5, SHA1, C4 (slower). Three modes: `Transfer` (file-size compare only, fastest; explicitly "do not use if erasing sources"), `Source` (independent source checksum re-read + destination size check), `Source & Destination` (full readback both sides, ~2× slower; required for ASC MHL). Formerly branded "Checkpoint" pre-24.3. MHL-aware: existing (ASC) MHLs on the source are reused instead of re-reading, but only when size and mod-date match. Auto re-verification of the destination MHL when a destination goes idle, with automatic re-copy from source or another destination on failure. Manual verify by double-clicking an MHL; batch verify a whole drive (Windows 25.2+). Broken Media Detection alerts on 0-byte files (common on improperly ejected exFAT cards); end-of-transfer missing-file check.

**Multi-destination and cascading** — unlimited simultaneous destinations (standard tier). Cascading (25.1+): copy to fastest drive first, then fan out from it so the card can be ejected early; base license = one cascade destination, Pro = groups/waterfall chains. Caveats: cascading transfers aren't MHL-aware yet, don't appear in Connect, and can't cascade from S3 ([cascading](https://docs.hedge.video/offshoot/features/cascading-transfers)).

**Organization/presets** — filter by extension *and* by filename substring, in `Do not copy` or `Copy only` mode; rename format and folder format built from draggable Elements ({Source Name}, {Date}, {Counter}, plus custom ones like Project/Scene). Presets are plain-text `.hedge` files in `~/Library/Preferences/Hedge/Presets`, editable and shareable by double-click ([organization](https://docs.hedge.video/offshoot/features/organization), [elements](https://docs.hedge.video/offshoot/features/elements)).

**Camera card handling** — Codex/ARRIRAW/ALEXA 35 HDE copy engines (Pro), with an "Incomplete Codex disk detected" guard that re-checks the VFS file system before and after transfer. Integrations: ProGrade and OWC card health checks (via privileged helper tools), ParaShoot for card wiping (rename-aware since 24.4), Frame.io, Scratch, iconik, FoolCat, EditReady ([integrations index](https://docs.hedge.video/llms.txt)).

**Logging/MHL** — per-transfer Transfer Log always saved locally (`~/Library/Application Support/Hedge/Transfer Logs`) and optionally on destination; skipped duplicates logged under `-- Skipped files (already on destination) --`. Legacy MHL for all tiers, ASC MHL (Netflix-required) Pro-only. HTML+PDF Reports (26.1+) aggregate multiple logs with logo/title/note and optional clip thumbnails + metadata ([reports](https://docs.hedge.video/offshoot/features/reports.md)).

**Automation (Pro)** — `offshoot://` URL-scheme API (open/quit/activate/setDestination/chained JSON actions), plus scripts bound to events: Disk Added/Removed/Busy/Idle, Source Added, Transfers Added, File Copy Completed, Verification Issue. Watch folders exist only as a sample AppleScript/PowerShell recipe using macOS Folder Actions, not a built-in feature, and the transcode half requires EditReady to be open ([watch folders](https://docs.hedge.video/offshoot/features/automation/examples/watch-folders.md)). OffShoot Helper is a macOS menu-bar app that loads JSON "Workspaces" (destinations + presets + settings) in one click.

**S3 (Pro)** — destination-only; verified via server-side multi-part MD5; certified providers AWS, Backblaze B2, Wasabi, Storj, Seagate Lyve, Amove, Perifery, Symply Nebula. Cannot handle empty folders, symlinks, 0-byte files, or >5TiB files; FoolCat/EditReady/iconik integrations don't work on S3 ([s3](https://docs.hedge.video/offshoot/features/s3-transfers.md)).

## 3. What it does NOT do

No search, no catalog/library, no asset browsing after the fact, no tagging beyond transient per-source Labels and folder/filename tokens. No playback or thumbnails except as report artifacts. No transcoding or proxies — that's the separate paid EditReady app. No PDF clip reports natively (FoolCat's job) until 26.1's Reports. No LTO (Canister). No card formatting/wiping (ParaShoot). S3 as source unsupported; Time Machine volumes and remote (unmounted) servers not visible. Finding duplicates already on a drive is out of scope — docs point users to third-party tools.

## 4. Pricing

Perpetual, no subscription; one year of updates/support included, renewable at reduced cost. Current: OffShoot **$169**, OffShoot Pro **$249**, project rental **$49/30 days**, Solo (iPad) **$49** ([hedge.co pricing](https://hedge.co/products/offshoot?features=all)). Was $149/$249 at launch in 2023 ([theasc.com](https://theasc.com/article/hedge-announces-offshoot-ecosystem/)), and ~$39–$50 in the Hedge era. Licenses are per-activation and can float between machines; extending has been quoted at $79/activation, Pro upgrade $49/activation ([FAQ](https://hedge.co/blog/faq-from-hedge-to-offshoot)). 10-day full-featured trial. Windows VM/hypervisor activation is Pro-only.

## 5. Praise vs. complaints

**Praise:** speed above all — an independent bake-off found Hedge fastest against Shotput Pro, Silverstack, and YoYotta, though the author later flagged that Hedge was doing a different ("new school") verification, making it not apples-to-apples ([filmdrives.com](https://filmdrives.com/blogs/blog/what-is-the-fastest-offload-software.html)). Simplicity ("three clicks", low configuration burden), reliability, cross-platform parity, and background copying while the DIT works elsewhere ([reduser thread](https://reduser.net/threads/what-are-people-using-for-data-management.154042/), [lambdafilms.co.uk](https://www.lambdafilms.co.uk/offshoot-video-software/)).

**Complaints:** price is the dominant one — the jump from ~$39 Hedge to $169/$249 drives alternative-shopping ([tuskbackup.com](https://tuskbackup.com/blog/hedge-alternatives-mac)); note that source is a competitor's marketing blog, so treat it as directionally rather than neutrally true. Feature-gating behind Pro (API, scripting, Ingest Browser, ASC MHL) irritates users who had them cheaper before. Paying separately for Solo on iPad when already licensed on Mac ([App Store review](https://apps.apple.com/us/app/offshoot-solo/id1530905771)). No built-in card reformat after backup (ParaShoot only, and Mac-only integration at the time of that review). Operational friction: macOS Full Disk Access needed or drives read as empty, repeated helper-tool permission dialogs for ProGrade/OWC, APFS purgeable space causing false "does not fit" errors, `UNTITLED` cards not auto-appearing on Big Sur+ (worked around by polling the Disks view).

## 6. Ingest UX details relevant to a competing design

- **Card detection is polling-based**, not event-perfect: macOS's own volume-mount reporting for `UNTITLED` cards is unreliable, so OffShoot periodically refreshes the Disks view. Any competitor will hit the same OS bug.
- **No true auto-ingest out of the box.** Auto-start on card insert is a Pro sample AppleScript matching volume-name prefixes/substrings, and the docs advise disabling "Auto Source" and "Remember Destination" when using it ([auto-start example](https://docs.hedge.video/offshoot/features/automation/examples/automated-transfers.md)). This is a real gap to attack.
- **Duplicate detection is name + size + mod-date**, not content hash. Non-matching same-name files get Finder-style " 2" suffixes; a `defaults write SFIDefaultsSkipDuplicateDetectModificationDateCheck` escape hatch exists (26.1.2+). Identical content in a different folder is copied again.
- **Resume is re-run-and-skip**, not byte-level: partially copied/unverified files are deleted and recopied, and each resume produces a *new* transfer log and MHL covering only newly copied files — which complicates single-manifest-per-card assumptions.
- **Queuing granularity** is a first-class setting: Off / Single Source / Single Destination / Single Transfer ([queueing](https://docs.hedge.video/offshoot/features/queueing.md)).
- **Ingest Browser** (Pro, 24.4+) is fully keyboard-driven — arrows to walk the tree, space to toggle, shift-space/Ctrl-A to select a level, Cmd-Enter to label, Enter to commit — and each selected folder becomes an *independent* source with its own preset/label. Worth matching.
- **Sleep prevention** during transfers; hidden system files (`.DS_Store`, Spotlight, Time Machine) are never copied, which is why source/destination folder sizes legitimately differ.
- **Escape hatches are `defaults write`/registry keys**, not UI — log location, underscore forcing, S3 multipart size/concurrency, alert auto-dismiss. Settings export/import is a raw plist/reg dump.
- Verification default is the *weakest* mode (size-only). The docs' own warning — don't use it if you're erasing sources — suggests a safer default is a differentiator.
