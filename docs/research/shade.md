# Shade (shade.inc) — Research Report

## 1. Core purpose, target user, platform, architecture

**Purpose:** An AI-native media asset management + cloud storage platform pitched as a "single source of truth" that collapses a 6–7 tool stack (LucidLink, Frame.io, Iconik, Dropbox/Drive) into one product ([shade.inc/why-switch](https://shade.inc/why-switch), [cined.com](https://www.cined.com/shade-at-nab-2026-an-ai-powered-system-from-ingest-to-delivery/)).

**Target user:** Video post-production studios, creative agencies, sports media teams, brand/content teams, houses of worship. Explicitly *not* solo creators or document-heavy orgs ([hackceleration.com](https://hackceleration.com/labs/review/shade), [blocksentient.com](https://blocksentient.com/review/shade/)).

**Platform:** Web app (app.shade.inc) + desktop app for macOS (Intel + Apple Silicon), Windows, and Linux (Debian/Fedora). Adobe Premiere Pro panel shipping; Resolve and Avid panels announced but not released — those connect via the mount ([cined.com](https://www.cined.com/shade-at-nab-2026-an-ai-powered-system-from-ingest-to-delivery/)).

**Architecture — important nuance:** Shade is **cloud-first now, but was local-first originally.** Legacy docs describe it as "a fully-local, AI-powered file browser… your assets, your data, is completely on your computer and never accessed by any Shade member," with user-selectable AI models and local rendering via installed apps (Maya for `.mb`, Blender for `.blend`) ([shade.mintlify.app/getting-started](https://shade.mintlify.app/getting-started)). The current product is the opposite: object storage in the cloud, cloud indexer nodes, a FUSE-based virtual filesystem. Founders confirm a multi-pivot history (started in crypto) ([Brandon Fan on LinkedIn](https://www.linkedin.com/posts/brandonfan1256_ive-always-been-hesitant-to-share-our-journey-activity-7394690497648398336-nPhj)). Reviewers note "a fully offline, local-only workflow is off the table" ([hackceleration.com](https://hackceleration.com/labs/review/shade)).

**Stack:** FUSE on macOS/Linux, WinFSP on Windows. Blobs live in S3-compatible object storage (default subprocessor: **Backblaze**); metadata, EXIF, tags and **AI embeddings live in Postgres on Google Cloud**. CDN in front of S3 with nearest-server upload then origin sync ([coderlegion.com](https://coderlegion.com/6364/new-york-startup-replaces-three-media-tools-with-one-platform-using-fuse-and-custom-models), [academy.shade.inc/our-storage-and-subprocessors](https://academy.shade.inc/help-center/general-faq/our-storage-and-subprocessors.md)).

## 2. Key features

- **AI semantic search:** natural-language full-sentence queries ("person skiing while holding a laptop", "CEO soundbite about sustainability") returning clips *with timestamps*. `cmd+K` searches the drive, `cmd+F` the current folder. Docs explicitly tell users to write descriptive sentences, not keyword lists, because "Shade's AI is not centered around tags" — tags are a curated 1,500-word snapshot layered over embeddings ([ai-search-best-practices](https://academy.shade.inc/ai-tools/ai-search-best-practices.md)).
- **Face recognition ("People"):** per-drive scoped face clustering. Unidentified faces surface in an asset's Details tab; you name a profile with 2–3 sample images. Composable with semantic terms ("JJ throwing a football") ([facial-recognition](https://academy.shade.inc/ai-tools/facial-recognition.md)).
- **Transcription:** timecoded, semantically searchable, exportable.
- **Auto-metadata:** scene descriptions, shot type, jersey numbers, product/inventory labels, OCR, EXIF/IPTC/XMP/timecode extraction, AI photo culling (blurry/closed eyes/bad exposure).
- **Other:** proxy generation, version stacking, duplicate detection, snapshots/drive-history rollback (mount a read-only drive at an arbitrary timestamp), frame-accurate timestamped comments with annotations, watermarking, RBAC + public links, REST API + Python SDK (`pip install shade-python-sdk`), webhooks, Zapier, Slack, a no-code automations builder with Custom Objects.
- **File types:** claimed 100+ to 500+. Confirmed from the [supported-formats table](https://shadeinc.notion.site/Shade-Platform-Supported-File-Formats-47c995c3ad80483391bedea6c9ee2c9b): RAW stills (3fr, arw, cr2/cr3, dng, nef, orf, raf, rw2, x3f, iiq, exr, hdr, heic) and video (**braw, r3d, mxf, mov/ProRes, m2ts, hevc, mkv, webm**). Adobe project files (.aep, .prproj, .psb, .indd) work on the ShadeFS mount but **cannot be previewed** since they'd need rendering. Audio/3D/document rows exist in the table schema but returned empty on fetch — treat audio-stem support as unverified.

## 3. How AI indexing works

Cloud-side, not on-device. "A set of indexer nodes that index all of your assets across a variety of different jobs depending on the asset type. Typically, the longest jobs are proxy generation, and our core vision job that runs the embeddings and additional metadata." Proxies run at ~16x realtime frame-rate; processing is first-upload-first-index ([how-long-should-it-take-to-index-assets](https://academy.shade.inc/help-center/general-faq/how-long-should-it-take-to-index-assets.md)). Indexing fires automatically on ingest through the proxy + AI pipelines ([introduction-to-shadefs](https://academy.shade.inc/shadefs/introduction-to-shadefs)). A Jan 2026 release cut time-to-start-indexing on 40–100GB files by ~10x ([shade.inc/blog](https://shade.inc/blog/the-speed-update-2-3x-faster-uploads-downloads)).

**Contradiction worth flagging:** the current quickstart still says "Our AI models run locally, so you can expect some updates to take longer when we are updating the models on your machine" ([quickstart](https://academy.shade.inc/getting-started/quickstart)) — almost certainly stale copy from the local-first era. No public detail on GPU type, model families, or vector index implementation. Models are described as custom/in-house, trained on "internally curated, licensed or publicly available data," with a guarantee customer data is never used for training ([ai-faq](https://academy.shade.inc/help-center/ai-faq/do-you-use-our-data-for-training-your-ai.md)). Certifications: SOC 2 Type II, ISO 27001, GDPR, HIPAA, TPN.

## 4. Organization model

Four-level hierarchy: **Workspace → Drive → Folder → File**, plus orthogonal **Collections**. Workspace = team + billing unit. **Drive is the mountable unit** — one drive per client/project/shoot; recommended is drive-per-client. Collections are curated cross-cutting groups, shareable via public link, duplicable. Also: tags (AI tags separated from user tags), custom metadata fields per drive and per asset type, drive/folder templates, "People" as a browsable directory, and a spreadsheet-like collaborative view. Permissions inherit down the hierarchy with per-level override; guests can be scoped to a single folder or file ([Understand the Structure](https://academy.shade.inc/getting-started/publish-your-docs.md)). Folders can be right-clicked → "Exclude folder from AI" to keep them out of indexing and search.

## 5. Pricing

Two tiers, per-seat, no free plan (7-day no-credit-card trial). **Growth:** $35/seat/mo monthly, **$29.75/seat/mo annual** (15% off) — 1 workspace, unlimited drives, **unlimited AI indexing**, max 15 seats, 150 guests, **500 GB active storage per seat**. **Enterprise:** custom quote — unlimited workspaces/seats, 250 guests, 1 TB/seat, SSO/SAML, SCIM, audit logging, dedicated AM, migration ([shade.inc/pricing](https://shade.inc/pricing)). Note price inconsistency across sources: TechCrunch and blocksentient both report **$20/seat annual** ([techcrunch](https://techcrunch.com/2026/04/22/shade-lands-14m-to-let-creative-teams-search-their-video-libraries-in-plain-english/)) — likely a 2026 price increase. Real-world spend is much higher than sticker: Shade self-reports **average contract $10–15K/yr for a 10-user, 25 TB setup**. Storage overage fees apply. AI features are bundled, not credit-metered — though shade.inc/home describes transcription as "credit-based," conflicting with the pricing page.

## 6. Praise vs. complaints

**Praise:** the search bar is the consistent standout — "genuinely magical" if finding a clip is your daily bottleneck ([timeliner.io](https://timeliner.io/vs/timeliner-vs-shade-inc)). Byte-range streaming into an NLE without downloading. Format breadth (BRAW/R3D/ProRes) wider than general DAMs. Strong compliance posture and no-training guarantee. Low-friction onboarding, no mandatory migration.

**Complaints:** Upload/download performance on constrained bandwidth was a real pain point — a user reported the uploader "incredibly slow," crashing for a partner on slow internet and freezing their own session, explicitly worse than LucidLink ([feedback.shade.inc](https://feedback.shade.inc/p/bandwidth-issues-and-poor-uploader-and-downloader-through-the-desktop), Nov 2025; now marked Completed, with a rewritten uploader shipped in v2.3.7). Face clustering over-merges — one user asked to re-cluster a "mega super-set individual" polluted with many people's faces ([feedback.shade.inc](https://feedback.shade.inc/p/re-clustering-faces-based-on-updated-individual-to-face-mappings)). Uploads stalling at 100%. **Thinnest signal of all: essentially no independent review base** — 0 Capterra reviews, G2 returns 403, ~94 paying customers as of April 2026; every capability claim traces back to vendor material ([hackceleration](https://hackceleration.com/labs/review/shade)). Also: 15-seat hard cap forcing enterprise sales, no rights/licensing DAM workflows, fewer integrations than Frame.io, no Camera-to-Cloud equivalent, and cost-inefficiency for small agencies without huge archives.

## 7. Large libraries, offline, and disconnected volumes

This is one of the more technically interesting areas:

- **Local cache:** default **26 GB** in `~/.shade` (troubleshooting doc says 10 GB — inconsistent), relocatable to an external SSD, shared across all mounted drives. Docs recommend cache ≥ your largest working file to avoid eviction/redownload thrash, and require **APFS or NTFS — explicitly not exFAT** ([managing-the-shadefs-cache](https://academy.shade.inc/shadefs/managing-the-shadefs-cache), [troubleshooting](https://academy.shade.inc/shadefs/shadefs-troubleshooting-guide)).
- **Pinning for offline:** pinned files live in a **separate storage space exempt from cache size limits and eviction**, persist across restarts, and are fully usable offline. Offline edits are marked **"dirty"** and protected from eviction until synced. Pin hierarchy: pinning a parent folder includes children; unpinning an inner folder is a no-op if the outer is pinned. You can pin without mounting the drive. No pin limit beyond disk — and no guardrail: over-pinning will fill your disk ([pinning-files-offline](https://academy.shade.inc/shadefs/pinning-files-offline)).
- **Shared Cache (notable):** a headless on-prem LAN server binary. First team member's access populates it in the background; subsequent members get LAN-speed serving after a **permission check against the cloud**, avoiding cloud round-trips almost entirely. Auto-discovered via Bonjour/mDNS, no password. Configurable cache size (default 500 GB), local-disk or on-prem S3 backend, tunable chunk sizes (128 MB download / 64 MB upload) ([using-shared-cache](https://academy.shade.inc/shared-cache/using-shared-cache.md)).
- **BYOS3:** connect your own AWS/GCS/Wasabi/Backblaze bucket and pay for Shade as a service without paying for storage — but Shade **reformats the bucket into UUID-named blobs and chunks with no folder structure**, so it is no longer usable as regular file storage ([bring-your-own-s3-storage](https://academy.shade.inc/byos/bring-your-own-s3-storage.md)).
- **Scale claims:** 60M+ assets ingested in under a year post-launch; indexing "designed to handle millions of assets." Bulk migration is handled via **rclone**, and the desktop app is recommended over web for anything over 5 GB.

**Company context:** New York, founders Brandon Fan (CEO, information-retrieval research background) and Emerson Dove (CTO, roboticist); team includes ex-LucidLink and ex-Frame.io engineers. $20M total raised ($14M March 2026 led by Khosla Ventures, Construct Capital, Bling Capital; $4.2M seed Jan 2024 from General Catalyst, SignalFire, Contrary). ~$300K MRR as of Nov 2025. Founding year is reported inconsistently as 2022 (Blocks & Files) vs. 2024 (TechCrunch/AlleyWatch) — the 2022 date likely reflects the pre-pivot entity. Public launch was early 2025; NAB 2026 Product of the Year.
