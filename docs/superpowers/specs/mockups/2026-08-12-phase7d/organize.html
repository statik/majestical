Detail — the selection toolbar (lives in Browse and Search, not Organize)

Multi-select in any grid raises this bar; this is how assets get tagged and filed in bulk.

Majestical — Browse (3 selected)
3 selected Tag… File to node… Clear
  • ·“Tag…” opens a tag picker (existing tags + create new); “File to node…” a PARA node picker emitting one asset_para_set per asset — catalog metadata only, no files move. Both act on N assets and report “Tagged 3 assets” with any per-asset failures listed, never silently dropped.

My read: the two-column Organize keeps structure and vocabulary in one glance — they're both "the taxonomy," and merge/rename decisions often reference what's on the other side (a tag that should become a node, a node name colliding with a tag). The selection toolbar belongs to the grids because bulk curation starts from looking at assets, not from the taxonomy.
