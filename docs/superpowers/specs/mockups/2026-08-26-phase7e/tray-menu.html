Tray menu states

One menu-bar item, always present while the app runs. The status line at the top is computed from SchedulerStateOutcome (chunk 5's wire struct) and nothing else; the radio group writes back through set_throttle. The icon has three looks (idle, indexing, paused) plus an attention tint when the last batch failed.

Wire gap (declared, for Task 14): SchedulerStateOutcome cannot distinguish "no catalog selected" from "not ticked yet": both leave decision null. The scheduler loop already knows which (it holds when selected_catalog is None). Task 14's menu_model therefore takes the catalog-selected flag as a second input alongside SchedulerShared, read from AppState at rebuild time, rather than adding a field to the wire struct. If you would rather see it on the wire (so Settings can show the same thing), say so and Task 14 adds catalog_selected: bool to the outcome with a fixture update.

Pluralization: "1 items pending" is the existing copy pattern in the app ("1 results", watchlisted). The tray strings are new, so they pluralize correctly from day one: "1 item pending".

Behaviour agreed here, not drawn

Open MajesticalShows and focuses the main window; on macOS also restores the Dock icon (activation policy Regular).
Health…Same as Open Majestical, then navigates the webview to Settings (the navigate-settings event). Settings scrolls to the Health section.
Quit MajesticalThe only way to exit. Waits for the current batch to finish (batches are one per-kind-capped run, seconds to a minute), then exits. No confirmation dialog.
Closing the windowHides to the tray instead of quitting; on macOS the Dock icon goes away (activation policy Accessory) until Open Majestical.
Menu rebuildRebuilt whenever the scheduler state changes (each tick, and immediately after a radio click), so the status line is at most one tick stale.

Wording questions for review: (1) "Indexing slowly" vs "Indexing (low)" vs plain "Indexing" for the run_low line. (2) Whether Paused-by-you should still show the pending count. (3) "Quit Majestical" vs "Quit" (macOS convention is the app name). (4) Whether the "Last batch failed" line belongs in the menu at all or only as the icon tint plus Settings → Health.
